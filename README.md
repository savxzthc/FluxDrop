## What Is FluxDrop?

FluxDrop is a desktop app for sending one file from a Windows PC to a phone over local Wi-Fi. The PC hosts a temporary local HTTP download page, the phone opens it in a normal browser, and the file streams directly from the PC to the phone.

## Why FluxDrop?

AirDrop is excellent but Apple-centered, Bluetooth is slow for larger files, Google Drive requires an account and uploads to a cloud service, and USB cables are inconvenient. FluxDrop is intentionally narrower: choose one file, scan one QR code, download through the phone browser on the same network.

## Features

- Single-file PC-to-phone sharing
- Local HTTP server bound to a detected LAN address
- Cryptographically random one-time token with 160 bits of entropy
- 10-minute automatic link expiration
- QR code generated by the Rust backend
- Self-contained mobile download page with no external assets
- Real-time desktop transfer status and progress
- Manual cancellation from the desktop app
- Filename sanitization, HTML escaping, security headers, and invalid-token rate limiting

## What FluxDrop Does Not Do Yet

- Phone-to-PC uploads
- Multiple files or folder sending
- Cloud sync, accounts, login, or relay servers
- Encryption in transit

## Privacy & Security

FluxDrop never uploads the file to a server. It serves the file from your PC to your phone over your local network and stores transfer tokens in memory only.

FluxDrop v0.1 uses local HTTP, not HTTPS. Traffic between your PC and phone is not encrypted. Use FluxDrop only on your home or trusted networks.

Download links use URL-safe random tokens generated from 20 random bytes, expire after 10 minutes, and become invalid after one completed download.

## Requirements

- Windows 10/11 x64
- PC and phone on the same Wi-Fi network
- No phone app required
- Rust stable, Node.js LTS, and the Tauri CLI for development

## Windows Firewall Note

Windows Defender Firewall may ask whether to allow FluxDrop on private networks. Allow private networks so your phone can reach the local server. Do not allow public networks unless you understand the risk.

## Troubleshooting

- Make sure the PC and phone are on the same Wi-Fi network.
- Disable VPN software temporarily if the phone cannot open the QR link.
- Avoid guest Wi-Fi networks; many isolate devices from each other.
- Confirm Windows Firewall allows FluxDrop on private networks.
- Try another LAN address shown in the troubleshooting card if multiple adapters are detected.

## Manual QA Steps

1. Start the app with `npm run tauri dev`.
2. Choose a small test file with the system picker.
3. Confirm a QR code and local URL appear.
4. Scan the QR code with a phone on the same Wi-Fi.
5. Confirm the mobile page shows file name, size, and type.
6. Tap Download.
7. Confirm desktop status changes to Downloading.
8. Confirm progress reaches 100 percent.
9. Confirm the downloaded file matches the source file.
10. Refresh the phone URL and confirm the link is expired.
11. Start a second share and click Cancel link.
12. Open the cancelled link and confirm the mobile page says Transfer Cancelled.
